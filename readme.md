# 🔬 Editor Engine — Comprehensive Hybrid Canva & Document Studio

A high-performance hybrid editor combining rich-text document authoring (TipTap) and Canva-style vector canvas manipulation (Fabric.js), governed by a state-driven React 19 + Vite + Zustand architecture.

## 🚀 Features
- **Ribbon Formatting Toolbar:** Tabbed ribbon controls for typography, custom Google fonts, table themes, and text effects.
- **Dual-Layer Rendering:** Seamless synchronization between TipTap HTML document layer and Fabric.js overlay canvas.
- **Image & Shape Studio:** Advanced filter matrix, cropping, aspect ratios, masking, and dynamic shape generation.
- **Plugin Ecosystem:** Interactive MathJax equation builder and ABCjs sheet music notation with live MIDI synth playback.
- **Document Chrome:** Custom margins, rulers, snap guides, header/footer/watermark management, and multi-page support.
- **Export Engine:** Client-side high-resolution PDF/PNG exports and server-side Puppeteer export pipeline.

## 🛠️ Quick Start
```bash
npm install
npm run dev
```
